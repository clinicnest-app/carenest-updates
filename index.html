ClinicNest

Community Edition · free

Patient records for small clinics. It runs on the clinic's own computer, works without internet, and keeps the data in the clinic.

Install ClinicNestWindows 10 / 11 · Mac with Apple silicon

What the Community Edition includes

Patients

Registration, quick search by name, phone or ID, and each patient's visits and results over time.

OPD queue

Today's patients with daily token numbers: waiting, seen, and scheduled follow-ups.

Specialty forms

Eye clinic and ENT clinic forms (examination, refraction, audiometry, procedure notes), plus vitals and visit notes.

Diagnosis and prescription

ICD-10 diagnoses, a medicine list with usual doses, and printed prescriptions on your letterhead.

Photos and documents

Take photos with the phone's camera during the visit; add reports and old prescriptions as PDF.

Follow-ups and reminders

Next-visit dates, a calendar, and day-before reminders by call, SMS or WhatsApp through the clinic's own provider account.

Charges and receipts

Fees, discounts, payments by cash, UPI or card, printed receipts and the day's collection.

Whole clinic, one computer

Installed on one PC; reception, consulting room and phones open it in the browser. Only devices the doctor approved get in.

Your data stays with you

Daily automatic backups, encrypted with your backup password, and no cloud account.

Install

Install ClinicNest on one computer in the clinic. Reception, the consulting room and phones then open it in the browser over the clinic's Wi-Fi. No administrator password is needed.

Windows 10 / 11

Recommended: one command
  1. Press Windows, type PowerShell and open Windows PowerShell (not as administrator).
  2. Copy this line, paste it into PowerShell (right-click) and press Enter:
irm https://updates.clinicnest.app/install.ps1 | iex
  1. ClinicNest downloads, is checked, installs and starts. The browser opens in about 30 seconds.
  2. If Windows Firewall asks about ClinicNest / Java: tick Private networks and click Allow.
Or with the installer
Download ClinicNest_setup.exe64-bit · about 65 MB

Run it; Windows may first show a warning – see below.

Mac · Apple silicon (M1 and later)

Recommended: one command
  1. Open Terminal (Applications → Utilities, or ⌘ + Space and type Terminal).
  2. Copy this line, paste it into Terminal and press Return:
curl -fsSL https://updates.clinicnest.app/install.sh | bash
  1. ClinicNest downloads, is checked, is copied to Applications and starts. The browser opens in about 30 seconds.
  2. If the Mac asks "Allow ClinicNest to find devices on your local network?", click Allow.
Or with the disk image
Download ClinicNest.dmgApple silicon · about 70 MB

Open it and drag ClinicNest to Applications; the first start needs one extra step – see below.

Is the one command safe? It downloads the same installer as the buttons, from this site only, and checks it against a checksum file signed with ClinicNest's key – the same check every automatic update goes through. If anything was changed or is incomplete, nothing is installed. You can read the scripts first: install.ps1 · install.sh.
After installing: the first start asks for the clinic's details and creates the doctor's login. The other computers and phones in the clinic open the address shown in ClinicNest's status window under "On the other computers in the clinic" (for example http://192.168.1.10:8080) and register once.

If something goes wrong

Windows

"Windows protected your PC" – when running ClinicNest_setup.exe

The installer is not code-signed yet, so SmartScreen does not know it. Click More info, then Run anyway. The one-command install does not show this warning.

The antivirus warns or removes ClinicNest

New, unsigned programs are sometimes flagged. Restore ClinicNest from the antivirus quarantine and add it as an exception, or use the one-command install (the download is checked against ClinicNest's signature).

Phones or other computers cannot open ClinicNest
  1. They must be on the same Wi-Fi / network as the ClinicNest computer – not on mobile data or a guest Wi-Fi.
  2. Windows Firewall: open Windows Security → Firewall & network protection → Allow an app through firewall, click Change settings and tick Private for ClinicNest / Java (OpenJDK Platform binary).
  3. The Wi-Fi must be set as a Private network (Settings → Network & internet → Wi-Fi → your network).
  4. Company security software (e.g. FortiClient, other firewalls) may block incoming connections: ask your IT.
"running scripts is disabled on this system"

Paste the command exactly as shown (irm … | iex) – it does not need script execution to be allowed. If your organisation blocks it, use the installer button instead.

PowerShell says it cannot download

Check the internet connection and try again in a few minutes. Behind a company proxy, use the installer button.

The browser does not open

Wait 30 seconds after the first start, then open http://localhost:8080 on that computer, or click Open ClinicNest in ClinicNest's window.

Mac

"ClinicNest cannot be opened" / "Apple could not verify…" – after the disk image

The app is not signed with Apple yet. Open System Settings → Privacy & Security, scroll down and click Open Anyway next to ClinicNest, then confirm. Needed once. The one-command install does not show this message.

Phones or other computers cannot open ClinicNest
  1. They must be on the same Wi-Fi as the Mac – not on mobile data or a guest Wi-Fi.
  2. System Settings → Privacy & Security → Local Network: switch ClinicNest on. (This is what the "find devices on your local network" question sets.)
  3. Company security software (e.g. FortiClient) may block incoming connections even when it looks switched off: ask your IT, or quit it while testing.
  4. The macOS firewall, if switched on (System Settings → Network → Firewall): allow incoming connections for ClinicNest.
"needs Apple silicon" / Intel Mac

ClinicNest for Mac currently runs on Apple silicon (M1 and later) only. Use a Windows PC or a newer Mac for the clinic.

Terminal says "Not installed: …"

The download could not be checked – it was incomplete or changed on the way. Nothing was installed. Run the command again; if it keeps happening, write to support@clinicnest.app.

The browser does not open

Wait 30 seconds after the first start, then open http://localhost:8080 on that Mac, or use ClinicNest's menu-bar icon → Open ClinicNest.
