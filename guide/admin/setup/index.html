Set up the clinic

At its first start ClinicNest shows Welcome – set up your clinic and leads through nine steps. The first three are needed. The others can be left as they are; everything in them is also under Settings later.

Before you start

Section titled “Before you start”

Install ClinicNest on the clinic’s main computer first: see the installation guide. The browser opens with the first step when the installation is done.

How the steps work

Section titled “How the steps work”
  • Next saves what you entered on a step and goes to the following one. If something is not accepted, the step stays open and the field is marked.
  • A step left as it is, is simply passed.
  • Finish setup ends the steps at any point after the recovery code.
  • The list at the left shows where you are. After the recovery code is saved you can click any later step.

Step 1: Clinic

Section titled “Step 1: Clinic”

Field What goes in
Clinic name Needed. Printed on prescriptions and receipts.
Patient ID prefix Needed. One to four letters; ClinicNest suggests them from the clinic’s name. Patient IDs then look like SE-0001.
Address, City, PIN code Printed on the letterhead.
Phone 1, Phone 2 The clinic’s numbers. Phone 1 is the number patients are asked to call in reminders.
Email, Clinic registration no. Optional.
Specialty Which specialty forms and prints are offered. General forms are always included.

The patient ID prefix stays

The prefix is set here and cannot be changed in Settings later.

The server edition first asks here for the setup code shown at the end of its installation.

Step 2: You

Section titled “Step 2: You”

Field What goes in
Title, Full name The name is needed. Printed on prescriptions.
Qualifications, Medical registration no. For example MBBS, MS (Ophth). Printed on prescriptions.
Username Needed. ClinicNest suggests your first name.
Quick PIN Optional, 4 to 6 digits, for switching user quickly on a shared computer.
Password, Repeat password Needed. At least 8 characters, with letters and digits.

Tick I have read and accept the ClinicNest Community Edition licence terms and press Create clinic. The clinic is created and you are signed in.

Step 3: Recovery code

Section titled “Step 3: Recovery code”

  1. Press Print, or write the code down.
  2. Tick I have saved the code.
  3. Press Next to go on, or Finish setup to stop here.

The recovery code is shown only once

It is the way to set a new password when the doctor’s password is forgotten: Forgot password? on the sign-in screen asks for it. Keep it printed or written down, not on the clinic computer.

Step 4: Letterhead

Section titled “Step 4: Letterhead”

What is printed at the top of prescriptions and receipts, beyond the name and address: the tagline, the website, the logo (PNG or JPG) and the paper size (A4 or A5). Later: Clinic details and letterhead.

Step 5: Fees

Section titled “Step 5: Fees”

Type the clinic’s usual charges, for example Consultation and 500. Each becomes a button when a visit is billed. Later: Fees.

Step 6: Staff

Section titled “Step 6: Staff”

Press Add user for each person who works with ClinicNest, and choose Assistant or Doctor. Later, and the difference between the two roles: Users and roles.

Step 7: SMS

Section titled “Step 7: SMS”

This step can be passed. Without it, the reminders list opens the SMS app of the device with the text filled in, and a person presses send.

To have ClinicNest send the SMS itself, tick Enable SMS sending and press Add beside Provider: not set. The choices and their steps: Choose how to send SMS.

Step 8: WhatsApp

Section titled “Step 8: WhatsApp”

This step can be passed too; the reminders list then opens WhatsApp on the device. To have ClinicNest send the messages itself: Choose how to send WhatsApp.

Step 9: Backup

Section titled “Step 9: Backup”

ClinicNest makes a backup by itself every day. On this step:

  1. Type a Backup password of at least 10 characters, twice, write it down, tick the box and press Encrypt backups.
  2. Under Extra copy to, type the folder of a USB drive or of a cloud folder, and press Save.
  3. Press Finish setup.

Nobody can recover the backup password

It is needed to restore a backup on another computer. Keep it written down, away from the clinic computer.

More: Backup and restore.

After the steps: other computers and phones

Section titled “After the steps: other computers and phones”

The other computers and phones of the clinic ask for access once:

  1. On the clinic computer, open Settings → Devices. It shows a QR code and the address of the clinic computer.
  2. On the phone, scan the QR code with the camera; on another computer, type the address into the browser.
  3. The device asks for access and shows a 6-digit code.
  4. Back in Settings → Devices, the device appears under Waiting for approval with the same code. Approve it there.

More: Other computers and phones.

Then, every day

Section titled “Then, every day”

Find or register the patient → Start visit → forms, diagnosis, prescription → print → next visit. The user guide describes the daily work.

Help inside ClinicNest

Section titled “Help inside ClinicNest”

The ? button at the top right: Help for this screen opens the page of these guides about the screen you are on. The guides are inside ClinicNest and need no internet.
