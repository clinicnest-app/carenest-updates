Install the server edition on a Mac

Install the server edition of ClinicNest on a Mac.

With Docker: one command

  1. Have Docker Desktop installed and opened once. Open Terminal.
  2. Copy this line, paste it into Terminal and press Enter:
  3. ClinicNest, the database and the web server are installed; the same command updates them later.

Data in ~/ClinicNest-Server · 8 GB RAM recommended (4 GB minimum)

Without Docker: one command

ClinicNest Server with PostgreSQL built in – no Docker. It can run as a background service that starts with the computer, also when nobody is signed in. Installs beside the desktop edition without touching it.

  1. Open Terminal (Applications → Utilities, or ⌘ + Space and type Terminal).
  2. Copy this line, paste it into Terminal and press Return:
  3. ClinicNest Server downloads, is checked, is copied to Applications and starts. The browser opens in about 30 seconds, at http://localhost:8081.
  4. If the Mac asks "Allow ClinicNest Server to find devices on your local network?", click Allow.

Or with the disk image

Apple silicon: ClinicNest-Server.dmg Intel: ClinicNest-Server-intel.dmg

About 95 MB each. Open it and drag ClinicNest Server to Applications. Opens at http://<this computer>:8081 (the next free port when another program has 8081 – its window shows the address). Start with the computer… in its window runs it in the background.

Good to know

Backups are made by ClinicNest itself into the backups folder – copy it to another place regularly. With Docker, the server runs while Docker Desktop runs: keep the computer on, signed in and awake. Docker Desktop is free for organisations under 250 staff and USD 10 million revenue.

After installing

The installation asks one question and shows the address to open and a one-time setup code at the end: see During the installation. Already using the desktop edition? See Move from the desktop edition.
